selectfuzz

摘要

selectfuzz基于aflgo改进,使用了新的距离度量计算方法,和选择性路径探索

距离计算

使用一种方法,计算一个基本块到目标代码(基本块)的多路径到达概率

计算基本块到目标位置的概率p,将p的倒数作为距离,且算法假设每个条件分支的概率都相同

选择性路径探索

识别出相关代码区域,包括The path-divergent code 和 The data-divergent code.

前者可以帮助探索到目标代码区域，后者则会影响目标代码区域的变量（从而可以利用漏洞）。

并且只对此类基本块插桩

项目代码分析

流程分析

  1. ./llvm_mode/afl-llvm-pass 在预处理模式下遍历函数和基本块,并输出相关文件
  2. scripts/distance.py add_edges.py等.对1输出的文件进行计算,控制流距离和调用图距离,并做选择生成keep集合 为pass的插桩功能提供依据.
  3. pass 依照2生成的信息进行插桩

缺陷

实际不是静态的数据相关分析,而是根据控制流距离和函数距离
