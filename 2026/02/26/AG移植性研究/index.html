AG移植性研究

摘要

AG是胡洁提出的基于DDB的变异算子选择算法

DIFF with Windranger

main函数

新增check_action_group_env() 11776 检查环境变量并支持禁用AG

新增

saveglobaltarget()

读取global_target.txt 格式为一串整数

读取整数后存储到 static int globaltarget[MAP_SIZE]; 按下标顺序存储

返回整数个数

savepreList()

为 static adjBasicBlock *preList; 动态数组分配空间

读取preList.txt 结构为 后面紧跟adjacent_count个整数

按下标存储到动态数组preList中

返回条目数量

sortList()

对preList 动态数组排序,用BB number作为下标,但是疑似存在小bug

savesucList()

为sucList 分配空间 功能同savepreList函数

readDistanceAndTargets() 改动

新增 static int target_book[MAP_SIZE];

读取distance.txt 时,如果距离为0,计数并存储target_book[num_target]=idx;

target_book[0] = num_target; 第一个存储目标总数量

initializeActionGroup()

初始化随机数种子

调用loadStaticData()

loadStaticData()

加载三个文件

critical_bytes.txt

格式: bb_id:byte1,byte2,byte3 例如：123:4,8,15

读取后写入：
bb_byte_mappings[bb_byte_count].bb_id = bb_id
bb_byte_mappings[bb_byte_count].bytes[…] = 每个 byte
bb_byte_mappings[bb_byte_count].byte_count = 字节数
最后 bb_byte_count++

constraint_type.txt

格式：每行
bb_id:ct
其中 ct 取值 0/1/2（约束类型枚举值）

bb_constraint_mappings[bb_constraint_count].bb_id = bb_id
bb_constraint_mappings[bb_constraint_count].constraint_type = ct
最后 bb_constraint_count++

bb_distance.txt

格式：每行
bb_id:distance

先写到 bb_distance_mappings[bb_distance_count]：
.bb_id = bb_id
.distance = dist
bb_distance_count++
然后再同步到全局 distance_val[]：
dist_int = (u32)(distance * 100.0)
distance_val[bb_id] = dist_int（按规则填充/覆盖
