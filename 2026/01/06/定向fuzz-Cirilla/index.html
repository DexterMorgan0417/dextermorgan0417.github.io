定向fuzz-Cirilla

DGF的定义

DGF(Directed Gery-box Fuzzing) 定向灰盒模糊测试,相比于传统模糊测试,集中资源进行探测给定的程序位置,为目标漏洞是否完整修复,和验证静态分析报告等需要有重要作用

主要指标

TTT：Time-to-Target 从开始 fuzz 到：第一次执行到目标位置
TTC：Time-to-Crash 从开始 fuzz 到：第一次触发目标bug
距离下降速度 (距离类引导fuzz中)

数据分析与处理

fuzz结果数据

fuzz的数据跨度非常大 并且不满足正太分布
推荐使用 Median + IQR(中间 50% 数据的范围)

性能分析和优化

记录执行速度曲线
定义距离下降速度 distance-down-speed=下降的距离值/中间执行了多少次目标

静态分析

原本的思路是用BB树来进行描绘 但是发现树容易产生重复的节点 甚至出现节点数量爆炸情况
现在退而使用DAG图
构建的算法;

输入： 模块 M，目标块 T
输出： 有环图 G，再从 G 抽出 DAG

1. 反向切片

  • 从 T 所在函数沿调用者往上走，得到函数集 Rf
  • 在 Rf 里从 T 沿 CFG 前驱、调用点往回走，得到 BB 集 Rb
  • Rb = 能到目标的块，Rf = 能到目标的函数

2. 哪些函数进图

  • 先放 Rf（以及 main）
  • 若图中函数直接调用了带 read/fread/recv 的 g，把 g 放进来
  • 再扫全模块，带这些填充 API 的函数也放进来
    得到 Fgraph

3. 建图 G

  • Rf 里的函数：节点 = 函数入口 + 该函数中属于 Rb 的 BB
  • 填充包装函数：节点 = 该函数全部 BB
  • 同一 LLVM BB 只对应一个点

边：

  • cfg：两端都在点集里，才连 CFG 后继
  • call：块里直接调用 g，且 g 的入口已在点集里，则连到 g 的入口

G 可以有环。根 r = main 入口，否则目标函数入口。

4. 从图做 DAG
对 G 的 cfg+call 出边 DFS，颜色 0 白 / 1 灰 / 2 黑：

Edag 无环，Esum 是循环或递归回边。菱形汇合留在 Edag。间接 call 目前不进 call 边

距离引导

静态+动态
对DDB分支计算一个静态分数 分数越难表明越难突破
基于图进行计算BB的深度,理论上一次执行 要么到达目标 距离为0 要么出现分叉 必定在某个DDB分叉 此时只使用该DDB的距离
距离算法:
目标为源的反向 BFS
图：节点 = 唯一 BB；正边 = cfg_succs ∪ call_succs；反边已经存在，就是 preds。
dist[v] = ∞
q ← 所有 is_target 的节点
对每个目标 t：dist[t] = 0
while q 非空:
u = q.pop
for p in u->preds: # 谁能一步走到 u
if dist[p] == ∞:
dist[p] = dist[u] + 1
q.push(p)

对每个 ddb_id>0 的节点 d:
ddb_dist[d] = dist[d] # ∞ 表示图上到不了目标

一次 O(V+E)，所有 DDB 的距离一起出来。无权最短路用 BFS；边权都当 1 就行，不必 Dijkstra。

距离含义
dist[d] = 从该 DDB 沿可到达后继走到目标最少经过几条边（BB 跳数）
越小越靠近目标；选种应优先小 dist，不要再用现在的正向 depth
走偏边本身不到目标，距离看的是 DDB 节点，不是那条偏离边

多路径问题

有些漏洞仅在某些路径才会出现
提出分支BB
定义: 此BB有多个后继 >=2 且后继中存在>=2到达目标的数量
branch BB
与DDB是交叉关系
对此BB进行插桩 与DDB一起得到轨迹哈希

变异器

生成目标数据结构

划分region种类
1.magic类 定义:此区域必须与某个常量值相等 只参与一处控制流比较 且是直接比较,后续不再参与控制流
2.len类 定义: 此区域的值作为某个长度 参与数据读取函数的长度参数 比如read fread等函数
3.数据类 定义: 此区间的值不参与任何控制流的数据流
4.控制类 定义:直接或间接参与的控制流 控制程序的执行
5.校验类 定义:用别的区段计算校验值 例如crc

region是可以重合的
每个region有如下属性
addr 相比于文件头的偏移
len 长度 定长/变长
type 类型 int uint 浮点 字符串

拼接目标结构

1. 顺序（头尾相接）

B.addr = A.addr + A.len（len 可以是公式）

这是默认组合。拼表时按 addr 排序，能接上就成一条链

2. 重合（同一段字节，多种类）

区间相交，不拆成两个物理字段，一块字节挂多个 kind：

物理上还是一个 region，变异时两种约束都要满足

3. 包含（大段里再划小段）

A.addr <= B.addr 且 B.addr+B.len <= A.addr+A.len → B 是 A 的子 region。

父可以是 data，子可以是 control/len。PNG 的 IHDR 就靠这个，不用新种类4. 联合

某块区域有多种类型 但只能是其中一种
